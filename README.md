# Ahmed Dawoud - Portfolio Website

This repository contains the source code for my personal portfolio website, designed to serve as a landing page for my professional profile.

## 🚀 Live Demo
You can view the website by hosting this repository on GitHub Pages or opening `index.html` in your browser.

## 🛠 Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom styling, Flexbox/Grid, Responsive Design (Dark Mode).
- **JavaScript**: Simple interactivity.

## 📂 Project Structure
- `index.html`: Main entry point.
- `css/style.css`: Stylesheet.
- `js/main.js`: Scripts.
- `PROFILE_BACKUP.md`: The original GitHub Profile README.
